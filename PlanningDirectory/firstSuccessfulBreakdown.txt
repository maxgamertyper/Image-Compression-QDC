META-DATA:
0x3C, 0x4D, 0x41, 0x58 = <MAX (file signature)
0x00, 0x03 = Major + Minor version (0.3)
0x00, 0x14, 0x00, 0x14 = Width, Height (20x20)
0x70 = flag bits (01110000, means maximum alpha, originally a png)
0xFF, 0xF2, 0x00 = initial colors (255, 242, 0)
0x0E, 0x61, 0x00, 0x00 = what i assume is the adler32 hash for the metadata
CHANNEL-DATA:
* this next part is repeated 3 times due to the 3 channels (R,G,B)
0x00, 0x00, 0x00, 0x04 = the channel length (4 bytes)
0x00 = how many trailing dead bits to fill the byte (0)
0x25, 0xA8, 0x05, 0x14 = the channel data (broken down below as it appears 4 times since its a uniform image)
0x02, 0xAE, 0x00, 0xE7 = what i assume to be the channel hash
TAIL:
0x00, 0x00, 0x00, 0x12 = R channel seek (18th byte is starting, true)
0x00, 0x00, 0x00, 0x1F = G channel seek (31st byte is starting, true)
0x00, 0x00, 0x00, 0x2C = B channel seek (44th byte is starting, true)
0x00, 0x00, 0x00, 0x00 = Y channel seek (0th byte means null because thats where metadata is, true because no gray channel here)
0x00, 0x00, 0x00, 0x00 = A channel seek (same as above, true because there is no alpha channel)
0xBB, 0xAC, 0x04, 0x8A = Should be the Adler32 hash for the whole file (again, not checking)

BREAK DOWN:
0x25 = 0010 0101 (first 4 bits is unary length, 2) (second 4 bits is first table mapping, 0 -> 5 bits)
0xA8 = 1010 1000 (first 4 bits is second table mapping (ESCAPE, 10 -> 10 bits)) (next 2 bits is starting OPCODE, 10 *rectangles) (next 2 bits start a color-value (0, 5 bits))
0x05 = 0000 0101 (first 4 bits finish the value, which = 0) (second 4 start the next value, 0 (5 bits) 101)
0x14 = 0001 0100 (first 2 bits finish the value, 10100 (20)) (next 6 bits start a new value, 0(5 bits)10100(20)

Means a rectangle of size 20 with paeth value 0
using the initial value we get a 20x20 square of 255, 242, 0
